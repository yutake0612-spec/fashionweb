# ファッションウェブ

WCB Fashion Collectionというアパレルブランドを想定した、架空のWebサイトです。

## 使用技術
- HTML / CSS / JavaScript
- ローディング画面のアニメーション(Animate API)
- スライドメニュー
- スクロールに応じたフェードイン表示(Intersection Observer)
